# AIBuddy Panel 3.0.5 · 安全存储、路由与代理整合

本次以定制版 `95a647a` 为基础，整合上游 Agent2API 正式版 3.0.5（`f8da217`，含 3.0.4），以及随后 beta 固定快照 `5eadcf0`。beta 功能随本次适配纳入，仍以本仓库的构建和验收结果为准。保留 AIBuddy-Panel 的默认更新源、本地品牌、shadcn / Base UI 界面和定制能力。

## 数据与安全

- 账号凭据和网关 Key 使用 AES-256-GCM 加密落库；密钥保存在数据库之外，支持 `AGENT2API_ACCOUNT_KEY`。普通数据库及 JSON 备份只记录密钥指纹，不携带密钥。
- 历史提供商、地区和名称独立于凭据保存。账号退出、删除或凭据无法解密后，已记录的历史归属继续保留；旧记录按可靠证据补齐，不猜测客户端来源。
- 避开上游与本地复用的数据库迁移编号，保留任务表与账号历史，在其后追加迁移。升级前使用 SQLite 一致性快照备份；旧对话正文不执行上游一次性清空。
- 保留请求、签到、任务及统计的可配置保留策略和现有值。新对话继续支持预览和排障。
- 保留受限 Key 的 Token 额度、有效期、模型与提供商范围，以及管理接口隔离。错误密钥不会把密文当成有效口令，也不会删除不可解密账号。

## 转发、会话与路由

- 修复空 reasoning_content 对终止帧、用量帧和错误帧的影响，保留工具调用思考签名，完善缓存 Token 别名、字符串数字及零值回退解析。
- 整合 413 与 beta 的确定性 404 不原地重发、家内轮询、显式会话标识、粘性及限流兜底修复。已保存的路由策略保持原值。
- 面板会话支持服务重启后恢复、Cookie 合并及刷新轮换；退出、改密和备份恢复仍会撤销旧会话。
- 新增长度截断自动续写接口，默认关闭、默认最多续写 3 次。开启后可能增加上游请求和用量，保留次数上限、工具轮及断线处理。

## 提供商、代理与模型

- 更新 OpenCode Zen/Go、CodeArts 积分去重和 Trae 中国版有效期。beta 的多提供商额度明细、缺失读数留空、过期份额折叠及套餐原文名称一并纳入。
- 代理支持监听端口范围、测试网址、按需监听、批量补建与端口回收；内核下载可选线路、目录并取消，保留现有代理引用与实际出口行为。
- 模型测试支持协议选择、临时代理和强制直连；增加自定义提供商模型聚合视图。
- 报表支持自定义日期与客户端来源字段，保留现有 Charts 配色、Token 数量读数、筛选和热力图。

## 界面、桌面与部署

- 任务中心统一签到、福利和 WorkBuddy 账号任务；原任务页改为系统维护，避免与签到入口重复。WorkBuddy 的任务和排程合并为同一组控制，完成后的结果从执行记录查询，保留在途停止入口。
- 查询任务后直接展示逐账号任务名称、进度、积分与能量奖励、领取状态和详情入口；选择单个账号时只查询该账号，并处理空结果、部分失败和切换账号后的过期响应。
- 补齐 OpenAI Responses 对话预览，兼容文本、工具调用与结果、推理摘要、图片及流式增量，并保持现有安全渲染和排障入口。
- 新增界面沿用 shadcn / Base UI，保留侧边栏、面包屑、页签、数字分页与行数、问号提示、接入文档和通知共享状态。适配小屏布局与 PWA 清单，继续使用本地品牌图标。
- 整合 Windows 内核黑框、静默执行及覆盖安装残留进程修复，保留 Windows/macOS 安装包构建。
- 新增 Linux amd64/arm64 服务端包、对应 `.sha256` 和数据库兼容清单；CI 检查前端源码与入库产物是否一致。
- 发版脚本校验构建提交、仓库、双架构 Linux 包和校验文件，兼容旧桌面版本；保留已有 dist 文件，校验失败时不发布。
- 容器自更新默认关闭（`AGENT2API_SELF_UPDATE=0`）。显式启用后仅管理员可执行，校验或兼容性检查失败不替换程序。更新与回滚均处理程序和界面；上一版本不兼容当前数据库时阻止直接回滚，需离线恢复升级前备份，不自动覆盖升级后的新数据。

## 升级前须知

请单独安全备份 `account.key` 或对应环境变量，并保存升级前数据库。只有数据库文件无法恢复丢失的加密密钥。容器内更新改变可写层，重建容器会恢复镜像内版本，应确认镜像、数据库与界面版本兼容。本说明是待发布草稿；验收、提交、推送、生产重启及正式 Release 分别安排，不会自动发布原 3.0.3 草稿。
