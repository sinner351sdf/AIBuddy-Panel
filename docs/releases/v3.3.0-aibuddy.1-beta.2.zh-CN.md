# AIBuddy Panel 3.3.0-aibuddy.1-beta.2 · 插件化迁移与本地定制保留

1. 更新：以 Agent2API 3.3.0-beta.3 为主程序基线，以 Agent2Providers 0.2.2-beta.2 为插件基线；保留 AIBuddy 定制与独立更新来源。
2. 新增：aibuddy-providers 独立提供商增强包，提供商推理、登录、续期、模型目录、余额、签到和成长动作统一通过 RPC；增加 AtomCode、LobsterAI、ModelScope 能力。
3. 保留：Accio ADK v2、SecurityGuard、工具历史恢复、本地 AI SDK 助手、附件草稿、工具确认与撤权，以及 WorkBuddy 持久任务队列。
4. 兼容：保留现有 /v1 和管理接口、schema 17、账号标识与顺序、凭据、历史、规则和任务；插件管理仍限定管理员会话。
5. 优化：账号批量设置、模型路由与缓存、恢复进度和侧边栏持久化；修复清理事务、规则编辑及 Token 阈值校验问题。
6. 修复：Accio SecurityGuard 初始化及 Cookie 恢复逻辑，准确区分 WAF_BLOCK、上游拒绝与本地鉴权错误；WAF_BLOCK 仍未证明完全解决，需用户后续重新授权验证。
7. 修复：管理员会话到期后的续期与退出流程，避免网关 Key 代替管理员权限；修复签到与福利列表图标、布局、账号明细及窄屏样式。
8. 优化：主程序和插件使用独立标签、更新通道及附件校验；保留源码 SHA、校验和与构建来源验证，冻结 Android 旧基线，本轮不生成新 APK。
9. 修复：跨平台构建验证，包括 Linux 容器嵌入资源、Windows 线程 API 依赖、移动产物复现和插件 Demo 验收隔离。
10. 版本：已发布 3.1.0-aibuddy.1 → 拟发布 3.3.0-aibuddy.1-beta.2。

## 已知限制

Accio WAF_BLOCK 仍待重新授权后验证。跨平台安装包由后续成功 CI 构建提供；本地模拟验收不等同于全部平台和真实提供商验证。Android 继续使用冻结旧基线，不包含新 APK。主程序和提供商插件分别安装、编号和更新。
