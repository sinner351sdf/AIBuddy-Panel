# AIBuddy Panel 3.0.2：上游同步与账号管理优化

本次发行将 AIBuddy-Panel 同步到 agent2api 3.0.2，并整合此前 beta 的管理功能，保留品牌设置、积分构成、WorkBuddy 成长任务、通知和远程同步等定制能力。基础代码来自 [aimod-cc/agent2api](https://github.com/aimod-cc/agent2api)，本仓库继续维护定制版本。

发行标签为 `v3.0.2-aibuddy.3`，程序内版本及安装包版本仍为 `3.0.2`；`aibuddy.3` 用于区分本仓库的发行记录，并不代表上游推出了另一个版本。本条为正式 Release。

## 上游同步与新增功能

- 同步 agent2api 3.0.2。核对上游 201 个变更路径：154 个与上游一致，47 个作定制适配，没有发现遗漏的变更路径。该核对结果不等同于所有外部账号均已联调。
- 接入 OfficeAce / 果办 / OfficeClaw 的登录、凭据导入、模型目录、额度、转发、签到与福利流程。
- 增加顺序优先、负载均衡、会话粘性、失败退避、429 调整及熔断等路由能力，支持候选账号原因预览和请求路由回放。
- 移植多条签到计划、每账号签到记录、保活模型编辑及验证码池设置，补齐各提供商的账号并发上限处理。
- 新增单账号 WorkBuddy「任务」弹窗，可查询任务进度与奖励，接受任务、领取奖励并执行支持的自动任务；与账号行操作衔接。
- 保留现有主题、页签、移动布局、品牌自定义、积分构成、受限 Key、通知、审计、备份及远程同步功能。

## 账号池与余额显示

- 修复网页端整组拖动和组内拖动排序：补齐排序桥接，纠正目标索引，处理拖动结束、取消和指针清理，防止顺序跳动或拖动状态残留。
- 没有在途请求时，连接数明确显示 `0`。
- 余额优先显示数值和原单位，例如 `0 credits`、`9598 积分`、`800万 token`；去掉「可用」前缀，移除全局余额模式切换。仅有百分比数据时显示进度条。
- Accio 套餐余量显示为 `698 credits` 这类数值；套餐总量和周期额度保留在明细提示中。修正周期百分比换算，缺失或无效额度不再伪装为 100%。
- 余额不足等提示改为在余额下方排列；分组顺序文案调整为「路由优先级 N」，数值较小的分组优先尝试。

## 登录、权限与恢复修复

- 修复 Qoder 等网页登录取消后无法再次打开的问题。关闭授权窗口或账号弹窗会结束当前等待；旧轮询和延迟返回不会干扰新一轮登录。此项已完成模拟生命周期验证，未使用真实 Qoder 账号完成授权。
- 有额度、有效期、模型或提供商限制的 Key 不能调用管理 API；面板会话和桌面内部管理凭证独立授权。
- JSON / SQL 恢复前验证管理员记录和配置，阻止已注册实例导入缺少或损坏管理员的数据；恢复后清除旧会话，使用恢复后的管理员重新登录。
- 额度账本读取失败时拒绝受额度限制的新请求，并明确记录记账异常，避免将统计故障当作零用量。
- 探活检查实际响应内容，临时网络错误、429 和 5xx 不再被累计为永久认证失效。
- Codex 配置支持外部网关地址和 `CODEX_HOME`，保留已有 TOML 内容及备份，修正面板与推理端口混用。

## 配置与兼容性

- 继续使用 `agent2api.db`，保留旧 JSON 备份入口。整库 SQL 文件备份接口位于 `/api/backup/sql/*`，仅供本机桌面内部授权使用；网页仍使用 JSON 备份。
- Key 额度属于软额度：已获准的在途请求可以完成，并发时可能超出阈值。无任何限制的旧式 Key 仍兼容管理权限，应作为管理员凭据保管。
- Antigravity OAuth 客户端凭据改为环境变量 `AGENT2API_ANTIGRAVITY_CLIENT_ID`、`AGENT2API_ANTIGRAVITY_CLIENT_SECRET`；源码和安装包不包含默认凭据。
- 成长任务可能消耗积分或改变上游权益；自动调度默认关闭。真实提供商授权、任务执行、外部通知和远程同步仍需在自己的账号环境验证。
- 更新源指向本仓库。容器升级需要更新镜像或重新构建；发布 Release 不会自动替换正在运行的服务。
- Docker 流程已改为仅发布私有 GHCR，并增加发布前后可见性检查。**私有镜像目前尚未发布成功，仍需配置 `GHCR_PUBLISH_TOKEN`；本次 Release 不提供已可拉取镜像的承诺。**

## 安装包与验证

- 附件提供 Windows x64 NSIS 安装包和 macOS Universal DMG（Intel / Apple Silicon）。两者来自 tag 对应提交 `360cff421cd4a6c01a50e64370823c11afdd23b5` 的成功构建。
- macOS 安装包未配置 Developer ID 签名与公证。
- 3.0.2 审查阶段通过 466 项 Rust 测试、113 项隔离 HTTP 断言及 37 项 OAuth 环境断言；后续 WorkBuddy 任务批次通过 468 项 Rust 测试。
- 余额展示、Accio 额度、账号排序和网页登录取消生命周期回归检查通过；私有发布检查通过 13 项测试。以上结果来自对应修改批次，未宣称所有外部服务实测通过。
