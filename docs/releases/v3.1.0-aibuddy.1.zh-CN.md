# AIBuddy Panel 3.1.0 · 移动端完整功能、Agent 配置与单任务执行

本次将已在本机使用的 3.1.0 beta 集成与后续修复整理为 AIBuddy 定制正式版本，基于上游 Agent2API 3.1.0，保留本项目的 Accio ADK v2、任务持久队列、网关 Key 权限与额度、助手历史、品牌及默认更新源。发布标签为 `v3.1.0-aibuddy.1`，应用和安装包版本为 `3.1.0`。

1. 新增：手机 Web/PWA 入口与完整共享功能页。账号、模型、Key、代理、Agent、签到任务、积分报表、请求日志及设置在同一手机页面内使用，不再嵌入桌面面板。
2. 新增：手机 AI 助手完整聊天能力，包括历史、模型与思考等级、附件、流式回答、停止、重试、工具授权和逐次确认；切页保留文字及附件草稿。
3. 新增：Agent 客户端配置管理，支持预览、手动应用、备份和恢复。进入页面只读取；实际写入验证网关 Key 权限、有效期及本机地址，预览隐藏凭据，备份失败中止，写入失败回滚。
4. 优化：手机添加账号改为提供商选择与表单两步流程，共用登录、短信、OAuth、二维码与文件导入引擎；返回保留输入，失败可重试，空白密钥不覆盖已有凭据。
5. 优化：手机报表增加日期筛选、Token／请求趋势及模型、提供商、账号排行；修复过期响应覆盖、失败筛选分页与窄屏布局，空数据保持明确空状态。
6. 优化：设置按 17 个分类组织并支持搜索；补齐手机偏好和通知抽屉，保留访问过的表单草稿，统一返回行为、触控区域与内容哈希缓存更新。
7. 优化：桌面启动及页面切换使用共享骨架屏，保留导航外壳；已加载内容切换时避免反复闪烁，延迟与失败状态有明确反馈。
8. 新增：WorkBuddy 当前账号的单任务执行按钮。只执行所选任务，显示排队与执行进度、防止重复点击，完成后刷新详情；已领取、锁定和仅支持手动的任务保持不可执行。
9. 修复：WorkBuddy 定向专家与连续任务的接取、进行中恢复和完成确认；旅行能力接入现有持久调度器，支持 HH:MM 时刻，避免重复消费同一调度配置。
10. 更新：同步上游 3.1.0 的提供商适配、思考等级、昨日统计及 Agent 相关改进，保留本项目 Accio、权限隔离与既有数据结构。
11. 修复：手机网页登录依赖桌面全局变量而无法发起授权的问题；补齐本机／远程服务状态、导出与 Android 网关桥的兼容处理。
12. 更新：增加 Windows amd64 无界面服务端包及 SHA256 校验；发布前校验安装包版本、构建提交、工作流来源、全部附件和下载地址，发布标题直接读取本说明。
13. 版本：3.0.8 → 3.1.0；AIBuddy 发布标签 v3.0.8-aibuddy.1 → v3.1.0-aibuddy.1。

## 验证与使用边界

发布前重新执行 Rust 库回归、服务端构建、桌面与手机 TypeScript/Vite 构建、前端回归、组件规范、隔离 API 及发布脚本模拟验证；最终计数和产物证据见同次发布验证记录。模拟测试使用临时数据，不使用真实提供商凭据，不替用户执行签到、领取奖励、付费推理或应用真实客户端配置。

手机布局及浏览器页面验证与实体设备验收分别记录。Android 客户端和内嵌网关源码保留，APK 由独立 Android Actions 构建与设备测试；本次正式 Release 不附 Android APK，也不使用旧 beta APK 充当新版产物。Windows、macOS 和 Linux 安装包由同一发布 tag 的成功 CI 构建生成，跨平台实机安装及各家真实提供商端到端调用不属于本地测试结论。macOS 安装包未做 Developer ID 签名与公证。Docker 镜像另行构建，不属于安装包附件。

升级前请备份配置与数据库，并保留现有数据目录。已有账号、助手历史、网关 Key 与定时任务沿用原有持久化结构；Agent 配置只在用户明确点击应用后写入本机客户端。
