# AIBuddy Panel 3.0.7 · 提供商、余额、代理与 AI 助手升级

本次说明覆盖从本仓库正式版 **3.0.5 升级至 3.0.7** 的累计变化，包含上游 3.0.6、3.0.7 和本地定制。此前 3.0.5 已提前纳入的 beta 修复继续保留，不重复算作本次首次新增。保留 AIBuddy-Panel 品牌、更新源及现有网关架构。

## 提供商与余额

- 新增 OrcaTerm（腾讯云遨驰终端）：凭据粘贴和桌面登录态导入、静态模型清单、流式／非流式转发、套餐次数查询与 OAuth 自动续期。清单包含 Hy4-preview、Hy3、DeepSeek-V4.1-Flash；上游未挂载所选模型时明确报错，不静默换模型或返回空白回答。
- 自定义提供商新增七种余额查询方案：Sub2API、NewAPI、DeepSeek、OpenCode、商汤日日新、智谱、智谱 ZAI。需要额外身份的方案使用独立查询凭据并加密保存；其余复用账号已有凭据。
- 预置 API 新增 Sub2API、NewAPI、商汤日日新。OpenCode Go 接入分窗口额度；Antigravity 增加 5 小时／每周额度窗口和订阅档位。
- WorkBuddy 国际版对话请求头对齐官方 5.8.4，补齐会话、消息与追踪 ID；支持官方 `.info` 与 wb2api 嵌套／扁平 JSON 凭据导入，保留地区归属和备注名。
- AutoClaw 活动福利按积分流水确认到账，显示当日合计与逐笔明细，并覆盖新手期第 1–7 天登录奖励。

## 代理与订阅

- OpenCode Zen 可主动配置逐请求轮换代理出口，429 时有限换出口重试。此能力仅用于支持该模式的提供商，不自动改动已有账号出口。
- 支持本地 YAML 订阅导入、节点校验、按内容查重及重新选择文件更新；本地文件不执行远端刷新。
- 代理池镜像节点可本地禁用并关闭监听端口；节点测试走统一测试口，已引用节点继续保留专用监听。
- 手动关闭代理内核后，节点测试、保存账号引用、订阅同步、排队修复与下载结束均遵守停止状态，由用户显式启动恢复。

## AI 助手与历史对话

- 本地启用并增强 AI 助手，使用 AI SDK 与现有 Rust 网关，支持流式回答、思考与工具步骤、模型搜索和能力标签；加入图片／文本附件、拖放／粘贴、复制和重新生成。
- 对话保存在本地 SQLite，可搜索、重命名、切换和删除；刷新后恢复历史，恢复对话不会自动重新执行未完成的工具。
- 默认只启用模型列表与账号余额两个只读工具。修改配置和模型测试须手动启用，并逐次确认；停止后不再启动后续工具。聊天与设置共享权限，旧配置不覆盖新撤销的权限。
- 助手实际模型请求计入日志与用量报表，可按“AI 助手”来源筛选。上下文入口显示系统提示、工具、历史和草稿的本地 Token 估算；图片未计入，不等同于精确计费。附件目前支持规定范围内的图片和文本，不支持任意 PDF／Office 文档解析。

## 任务、补偿与账号池

- 新增国内版补偿状态查询与一键领取，接入任务中心和单账号任务列表。查询不领奖，领取前重新确认资格；重复点击、部分失败与丢失响应有保护，不盲目重发领取请求。
- 成长任务按普通／小程序平台一致地接受和回读，支持异步登记确认，用最新进度执行；已完成直接领奖、已领取不重复动作，未知状态不盲目重复写入。
- 国际版网页会话保活使用独立开关，默认关闭；仅领奖模式不创建网页会话。开启后可能在上游保留会话并产生用量。
- 积分明细改为可搜索侧边抽屉，区分可用与已用完／过期积分包；名称完整展示，金额最多两位小数，悬停保留精确值。
- 提供商统计独立一行，操作按钮集中到列设置栏；分组标题整条可折叠，拖拽和菜单独立；添加账号改为整张提供商卡片可点击，预置与同名自定义入口去重。

## 兼容与验证边界

保留现有账号、配置、历史身份、请求正文、任务记录、图表及可配置保留策略；保留期范围扩展到 1–99999 天，兼容上游字段别名，没有强制改为全量永久保留。路由、整库备份／恢复、验证码令牌池、models.dev、Cline 头配置及多语言入口继续保留。404 确定性失败、CodeArts 积分去重、Trae 中国版有效期和上游原文套餐名已在定制 3.0.5 中包含，本次延续。

数据库升至本地 schema 16 以保存助手历史；升级前请单独备份数据库和 `account.key`，只有数据库无法恢复丢失的密钥。恢复历史不自动调用模型或工具；较旧程序无法读取较新 schema 时应使用兼容版本或离线恢复备份。

当前源码验收为 Rust 700 通过、0 失败、7 项原有忽略，另有 1 项文档测试忽略；28 组前端回归和 8 组隔离 API 回归通过，前端／服务端构建及 macOS 源码编译检查通过，93 个生成产物重复构建一致。OrcaTerm 真实账号推理／续期、Windows/Linux 实机安装和新安装包构建未在该源码验收阶段执行；安装包与正式发布状态以对应 GitHub Release 为准。
