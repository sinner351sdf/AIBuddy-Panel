# AIBuddy Panel 3.0.8 · 提供商整合与 Accio ADK v2 升级

本次发布从定制版 3.0.7 升级至 3.0.8，整合上游正式版及选定 beta 更新，保留 AIBuddy Panel 品牌、更新源、本地 AI 助手、任务中心、账号历史和数据保留策略。发布标签为 `v3.0.8-aibuddy.1`，应用内版本号为 `3.0.8`。

1. 新增：智谱清言访客及登录账号接入，覆盖模型目录、转发、余额和签到；访客账号不显示未经确认的积分权益。
2. 新增：小浣熊、CatPaw、Cline Pass 和 KukuAI 对应凭据文件导入；新增默认开启的 developer 角色转 system 兼容开关，可在设置中关闭。
3. 更新：完善 OrcaTerm OAuth 扫码、CodeArts 授权打开方式、Cline Pass 预置配置及 ZCode 端点映射；修复 Antigravity 工具思考签名、额度处理和 Loomy 图片适配。
4. 更新：Accio 使用官方 v2 模型目录和真实模型代号，保留权限、图片能力和计费信息；对齐 OAuth 两阶段、用户资料查询和账号授权会话恢复。
5. 新增：Accio 官方 SecurityGuard 原生 SDK 的独立 Node 桥接，支持初始化、按请求生成因子和失败恢复。官方原生模块须由部署环境提供，安装包不包含该模块或账号凭据。
6. 修复：Accio 会话、用户轮次、消息及单次模型调用标识的生命周期；同次授权恢复保持标识，工具后续调用可承接返回的 accio_context，避免跨账号复用上下文。
7. 优化：分别诊断 Accio 的 WAF、账号限制、鉴权、额度、传输和协议错误；限制错误体读取时间与大小，请求明细保存脱敏诊断。
8. 修复：Gemini 工具参数与思考签名处理；工具结果因中断丢失时补充明确的错误占位，保留已有结果，不自动重复执行工具。
9. 更新：Accio 图片按模型能力处理，支持 PNG、JPEG、WebP，BMP、ICO 转为 PNG；校验真实格式、大小、尺寸与目标地址，重复图片在同次请求内缓存，不支持或失败时明确占位。
10. 新增：Accio 可选请求 gzip，默认关闭；仅满足大小及压缩收益条件时启用，无 WAF 或跳转拒绝的 HTTP 415 可原文回退一次，并保持同次调用标识和时间预算。
11. 修复：Accio 按完整 SSE 事件解析多行 data、跨块 UTF-8、换行、心跳及 EOF，避免预读丢失同块后续数据；提前断流和解析异常不再伪装成正常结束。
12. 优化：账号池、积分明细、补偿任务和代理监听器对账；缩小报表查询列、补充索引，减少数据未变化时的界面重绘。
13. 更新：数据库 schema 16 升至 17，仅新增索引，保留助手历史及既有数据策略；更新多语言文档、截图、语言词典、Markdown 表格和 React 生成资源。
14. 更新：beta 更新通道默认关闭，正确识别正式定制标签；新增 Linux deb、AppImage 桌面包及发布资产校验，保留 Linux amd64、arm64 服务端更新包和私有 GHCR 策略。
15. 版本：3.0.7 → 3.0.8。

## 升级与验证说明

升级前请备份数据库和 `account.key`；缺少密钥的数据库备份无法恢复加密凭据。旧版本无法读取新版数据库时，请使用升级前的兼容备份。

源码提交记录的全量服务器回归为 804 通过、0 失败、15 忽略；另有 8 个 gzip、11 个会话、18 个 SDK 桥接合成场景。该提交的前端构建、UI 回归、56 项隔离 HTTP 检查和 23 项发布脚本模拟场景通过。这些为已有源码验收记录，发布阶段另行核验 CI 构建来源、附件和校验文件。

上述验证不代表真实提供商账号推理、账号限制解除、全部图片格式等价或所有平台实机安装已通过。macOS 安装包未进行 Developer ID 签名和公证；Docker 镜像不属于 Release 下载附件。
