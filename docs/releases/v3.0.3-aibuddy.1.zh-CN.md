# AIBuddy Panel 3.0.3 · 界面、任务与历史数据更新

本次正式发行整合 agent2api 3.0.3 与本地定制，集中更新 shadcn 界面、任务中心、账号历史归属和通知同步。保留原有网关、账号池、配置与数据库。发行标签为 `v3.0.3-aibuddy.1`，程序及安装包版本为 `3.0.3`。

## 更新内容

1. 更新：同步上游 3.0.3 的提供商、订阅代理、模型资料和任务功能，保留本地品牌、网关路由、权限与转发定制。
2. 优化：统一采用 shadcn/ui、Base UI 与 Tailwind v4 组件，覆盖侧边栏、面包屑、页签、菜单、表单、弹窗和说明提示；保留原有功能与操作。
3. 优化：全站分页统一为可点击页码、前后翻页和每页行数设置；整理网关 Key 的显示、复制、快速接入和操作菜单。
4. 优化：用量统计迁移到 shadcn Charts，保留时间筛选、数据、图例和交互，热力图保留；缓存趋势展示 Token 数量与“万”单位，调整图表配色和环形图文字对比。
5. 优化：重排欢迎区和接入文档，突出 Base URL、协议端点、客户端示例和健康状态；地址变化自动同步示例。配置说明集中到问号提示，修复页面搜索英文标识对齐。
6. 修复：设置页与右上角铃铛共用同一套实时通知状态，打开通知、刷新或标为已读后两边即时同步；补齐延迟初始化订阅，避免显示过期计数。刷新失败保留已有事件，后到的新告警继续显示未读。
7. 修复：所有提供商及自定义提供商的账号退出或删除后，历史请求保留提供商、地区与显示标签；尽量补齐可靠旧记录，保持统计总量，没有可靠依据时不强行关联。
8. 更新：完善任务总览、自动排程、执行记录、筛选和保留期；补齐 WorkBuddy 扫码轮次隔离、取消、继续添加及异常处理。
9. 修复：适配 Accio 流式与阶段耗时、CodeArts 工具兼容、ZCode Coding / Start 自动选择与独立冷却，以及 Clash 和订阅节点路由。
10. 优化：发版复用 Windows 与 macOS 构建，两个平台成功后才发布正式 Release；核对源码提交、版本、产物和更新说明，附 SHA-256 校验文件。
11. 版本：3.0.2 → 3.0.3。

## 安装与更新

- Windows x64：下载 `Agent2API_3.0.3_x64-setup.exe`。
- macOS Intel / Apple Silicon：下载 `Agent2API_3.0.3_universal.dmg`。该包未配置 Developer ID 签名与公证。
- 安装包与源码对应本发行标签；`SHA256SUMS.txt` 提供附件校验值。
- 升级前建议备份配置与数据库，继续使用 `agent2api.db`。容器与源码部署需要自行更新镜像或重新构建；发布 Release 不会替换正在运行的服务。
- 更新源继续使用本仓库。3.0.2 客户端应识别到 3.0.3；已运行 3.0.3 的客户端应显示“已是最新”，同时展示本次发行说明和安装包。

- 提交前 Rust 测试 564 项通过、7 项忽略；服务端构建、macOS 桌面检查、前端构建和类型检查通过。
- 21 份前端专项脚本、12 项偏好测试、组件规范检查通过；任务中心 58 项、上游兼容 134 项、原面板 113 项、OAuth 37 项、成长任务 53 项隔离断言通过。
- 历史归属覆盖 23 个内置提供商及自定义提供商，检查删除、补齐、重启与统计稳定性；受限 Key、恢复与会话等安全边界回归通过。
- 浏览器检查覆盖通知双入口、文档复制、提示、深浅主题和窄屏。隔离验证使用临时数据库与虚构账号，不等于所有真实提供商授权、奖励到账或所有操作系统均已实测。
