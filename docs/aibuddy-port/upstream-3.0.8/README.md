## 必须保留的本地行为

- AIBuddy-Panel 更新仓库和私有 GHCR 策略、品牌资产、账号与 Key、历史提供商归属不改变。
- 本地 AI SDK 助手、SQLite 对话历史、附件、上下文估算、工具逐次确认及受限直连凭据保留。上游新增的 directCredentials 管理 Key 返回通道不引入。
- 任务中心、补偿积分、成长任务接受确认、独立且默认关闭的国际版网页会话保活、扫码登录与账号池交互保留。
- 保留原有请求正文、配置、日志保留天数和条数策略。未采用上游的自动历史正文清理或新的 1000 条上限。
- 本地 schema **16 → 17** 只新增状态与报表索引；16 的助手历史及更早的任务／账号归属表继续保留，拒绝新版库降级打开。
- `-aibuddy.N` 是正式定制版标识，不误判为 beta；显式 `-beta.N` 或 `-rc.N` 才影响预发布与镜像 latest。Linux 桌面加入发布附件来源、非空检查及总 SHA256。

## 合并时修复

1. 角色转换结果在提示词透传分支被旧原体替换，导致默认设置虽为开启但未生效；改为继续沿用转换后的副本，由 HTTP 转发测试证明。
2. 智谱清言续期按旧 access/refresh/device/guest 快照比较后回写，旧结果不能覆盖重导入或恢复已删除账号，落库失败返回错误；相关续期、目录、余额和签到沿用账号出口，无效代理不静默直连。
3. KukuAI 上传的临时 Cookies 文件使用排他创建及 Unix 0600，读取后无论成败删除。
4. 设置页合并造成两份角色兼容面板，保留一个 shadcn Card／Switch，并用真实组件渲染回归检查唯一入口。
5. 报表刷新时间从父页面状态拆到独立订阅，避免“数据不变”时仍因时间戳导致全部图表重绘。
6. 更新 npm 锁文件的根包版本至 3.0.8；补充 Linux 桌面与定制版 beta 的发布校验，并清除固定在旧版构建上的手动发布默认值。
