# Android 本机网关与远程面板

手机浏览器、PWA、APK 打开的管理面板共用 `desktop-tauri/ui/index.html` 与 shadcn ui-kit。旧 `/m`、`/m/`、`/m.html` 地址会保留参数并迁移旧页面选项，进入完整网页版。小屏侧栏收进抽屉，表格按现有响应式规则显示账号卡片，输入框、弹窗与安全区域适配手机。

APK 的首页负责服务选择：

- **本机网关**：手动启动 APK 内置的 Rust 网关，账号和数据库保存在应用私有目录。首次打开面板需要设置管理员并创建 API Key。同一手机的客户端可使用 `http://127.0.0.1:3065/v1`，不依赖电脑在线。本机仅监听回环地址。
- **远程服务**：可以保存多台 HTTP/HTTPS 服务；打开各服务自己的完整网页，各源维持独立登录状态。Android 返回键回到服务选择，不停止本机网关。

后台网关运行在独立的 `:gateway` 前台服务进程，并有通知栏停止操作。关闭面板不会主动停止网关；手动停止会关闭 HTTP 监听并退出这个独立进程，重启不会重复初始化后台任务。系统强制停止、清理进程或厂商省电策略仍可能中断服务，应用不会在重启手机后自动运行。

远程面板 WebView 不注入 Capacitor/native bridge。账号、Key、远程登录态不从桌面数据复制进 APK；Android 无法读取电脑上 AI 客户端的凭据或修改电脑客户端配置。依赖 Windows DLL、外部桌面程序或桌面登录态的提供商功能不保证在 Android 可用；须使用该提供商支持的网页登录/导入流程。

APK 的 Rust ARM64 / x86_64 动态库和 Gradle APK 全部由 `.github/workflows/android.yml` 编译。本机只进行 Web 构建、宿主机 Rust 检查和测试。CI 的 Android 模拟器测试会实际启动 JNI 网关，检查健康接口、完整面板资源、管理员认证、未配置 Key 时拒绝转发、界面退后台仍运行以及手动停止释放端口。模拟器通过不等于所有真实 ARM 手机及提供商登录/转发均验证通过。

生产签名仍留在本机；CI 产出独立 `.debug` 包和未签名 release 包，安装正式包前需使用原有私钥签名，才能覆盖升级。
