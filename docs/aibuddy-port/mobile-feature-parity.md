# 手机端功能核对（3.1.0 beta）

`/m`、`/m/` 和 APK 内的网关页面保留手机首页、卡片和五项底部导航。二级功能在同一个手机文档中挂载共享业务组件，不再嵌入桌面面板。

| 入口 | 手机界面与功能 |
| --- | --- |
| 添加账号 | 提供商单列卡片、搜索、内置登录方式、预置 API、自定义提供商；选择与表单为同一手机页面内的两步流程，无弹窗遮罩；返回保留输入，添加成功自动返回；保留各家登录引擎、文件导入、二维码、验证码和取消逻辑 |
| 账号详情与编辑 | 详情底部抽屉；基本、凭据与套餐、查询、限制器、网络五组手机表单；保存失败保留草稿，空白密钥不覆盖已有凭据 |
| 账号管理 | 账号卡片、搜索、勾选与批量操作、上移/下移、启停、余额与明细、套餐、WorkBuddy 任务、Cline Key、刷新与确认删除；顺序提交完整队列 |
| AI 助手 | 完整聊天、历史抽屉、模型搜索、思考等级、附件、上下文用量、流式回答、停止、重试、工具授权和逐次确认；切页保留文字和附件草稿 |
| 设置 | 17 类设置使用分类列表进入详情；返回先回分类列表；本机语言、外观、安装等偏好保留独立手机入口；更新分类直接渲染真实组件 |
| 模型 | 手机功能页承载模型清单、映射、自定义模型、能力和测试表单 |
| 网关 Key | 新建、范围、额度、有效期、接入说明、复制与确认删除共用正式组件 |
| 网络代理 | 代理池、分组、订阅、增加与编辑、测试及 Clash 同步；每次进入重新加载池数据 |
| Agent | 客户端清单、配置编辑、预览、手动应用及恢复；进入页面只读取配置 |
| 签到与任务 | 每日签到、补签、福利、套餐、成长任务、旅行、定时条目与记录，沿用上游动作语义 |
| 积分与报表 | 完整积分构成、趋势、日期筛选及导出 |
| 请求、日志和维护 | 筛选、详情、分页、维护任务和正式确认流程 |
| 接入文档 | 当前网关的真实地址、各客户端示例及检测；每次挂载重填地址节点 |
| 本机网关与远程服务 | 保留 APK 启动/停止本机服务和多台远程服务配置；远程 Dashboard 没有新增原生 JS 权限 |

通用接口由服务端的 canonical HTTP bridge 生成；手机通过自己的 HTTP 客户端处理会话刷新和认证弹层。同源网页与登录页共用凭据位置，旧手机凭据只迁移一次，APK 远程配置仍按服务隔离。OAuth 回调提示也使用手机 shadcn 对话框。

“导入”单独分段在上游本就关闭，仍不显示；各家已有导入方式以及设置中的账号/数据库导入导出保留。桌面窗口、托盘、宿主端口等能力仍遵守网页桥的能力限制。

## 手机网页登录点击修复

真实浏览器点击 WorkBuddy 的网页登录按钮复现 `ReferenceError: busy is not defined`。原因是 web-login.js 在 try 外直接访问桌面 app.js 的全局 busy，手机入口只加载共享业务组件，没有桌面全局。引擎改为使用自身的发起锁；桌面存在 busy/releaseBusy 时继续复用桌面锁和刷新队列。手机内容区删除重复的返回按钮，顶部返回仍先回提供商选择。

新增真实组件按钮 + canonical HTTP bridge + 原始 web-login.js 的模拟测试，不提供 busy/releaseBusy，验证点击发起、授权 URL 导航、重复点击保护、取消、复位；引擎生命周期测试同时覆盖手机无全局环境的成功、失败、重试和弹窗拦截。整轮 36 套测试及 shadcn 结构检查通过。

局域网浏览器已实际点击并确认进入等待授权、显示取消操作，取消后按钮恢复；顶部返回回到提供商列表。浏览器工具无法读取独立授权窗口，因此没有把授权页面加载或真实账号登录完成标为已验证。
