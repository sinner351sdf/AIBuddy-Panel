## 本地额外改动

### 成长任务接受确认

- 普通任务和小程序任务按各自平台接受、回读，避免确认错列表。
- 写入后进行有界回读，仅明确未接受时才允许有限重试；超时、缺失或未知状态不盲目重发。
- 后续执行使用回读后的新进度；已完成直接领奖，已领取直接结束；停止信号与仅领奖模式保持生效。
- 旧领养路径确认失败后停止，执行记录保留失败阶段与 HTTP 状态。详见 [成长任务修复记录](../growth-acceptance-fix.md)。

### 补偿积分

- 国内版单账号状态查询：`GET /api/growth-tasks/accounts/{account_id}/compensation`。
- 领取复用 `POST /api/growth-tasks/gift`，参数为 `accountId` 和 `kind: compensation`。
- 上游使用 WorkBuddy 网页域及 `X-Client-Platform: web`，身份和出网代理来自所选账号。
- 查询不领奖；领取在账号锁内重新确认资格，领取写入不自动重试；前端对重复点击、丢失响应、部分失败和切换账号作隔离。
- 单账号弹窗将补偿作为任务表首行；任务中心支持选定范围查询和领取。本轮使用夹具复验，此前已完成单个真实国内版账号领取与状态回读验证，没有在本轮重复领取。

### 账号池与添加入口

- 积分明细改为 Sheet 右侧抽屉，固定账号和余额摘要，按可用／已用完或过期分组，支持名称、来源和日期搜索。
- 金额最多显示两位小数，完整上游值保留在悬停提示；缺失值仍保持未知。
- 提供商数量独立展示，移除与下方筛选重复的顶部汇总；折叠、添加账号、查询余额移至列设置所在操作栏。
- 分组标题文字和空白区域均可折叠／展开，支持键盘操作，拖拽手柄和菜单独立。
- 提供商整张卡片可进入添加流程，移除右侧独立箭头按钮；保留键盘焦点和选择。

## 审查与修复

重点核查了提供商注册与模型接线、凭据公开形态、续期并发回写、代理出口、SSE 分块与错误、管理接口范围、任务重复写入、前端状态隔离及数据迁移。

- 保留 OrcaTerm 对旧 token 的比较后回写，避免旧续期覆盖重新导入的凭据或恢复已删除账号；续期身份变化和存盘失败明确报错。
- OrcaTerm 的额度缺失保持未知，真实零值保持零；续期和额度查询遵守账号出口，失效代理不静默直连。
- 保留本地 schema 16、历史身份、助手对话和请求正文保护，没有直接套用上游的历史正文清理迁移。
- 本轮补修：新分组按钮使用 `aria-expanded` 表达状态，但旧箭头样式仍依赖未设置的祖先 class；现在直接跟随按钮状态旋转。
- 本轮补修：3.0.7 UI 夹具断言已完成但 React 调度器 MessagePort 保持进程存活；补充定时器清理和成功断言后的独立夹具退出。失败断言不会被成功退出覆盖。
- README 顶部仍写 3.0.3，已改为 3.0.7，并补 OrcaTerm 与补偿入口说明；更新 CHANGELOG。

在本次审查和下列验证范围内，未发现剩余阻断提交的问题；这不等同于所有上游账号的真实服务端兼容性均已验证。
