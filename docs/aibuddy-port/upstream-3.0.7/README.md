## 用户确认的保活取舍

新增独立「网页会话保活」开关，默认关闭，路径：任务中心 → 定时签到 → WorkBuddy 国际版保活设置。

开启后仅 Full / Keepalive 模式额外向国际版创建带 Hi 提示词的网页会话；Claim 模式不创建。
这会在上游保留会话且可能产生用量。现有免费模型保活与模型链配置保持原行为；开关与模型链分别保存，旧客户端保存模型不会重置开关。

持久化键为 `checkinWebConversationEnabled`，缺失/非法值均视为关闭。写盘失败时不发布新内存状态，避免“保存失败但实际已开启”。开关不会开启自动签到总开关或修改任何计划。

## 同步时补齐的问题

1. OrcaTerm 续期按旧 token 比较后写回；拒绝覆盖重新导入的凭据，删除后的账号不会被恢复，写入失败中止使用新 token。
2. OrcaTerm 续期和余额查询沿用账号出口；无效出口不悄悄直连。续期响应身份变化时拒绝回写。
3. OrcaTerm SSE 按完整 UTF-8 解码，兼容跨分块 CRLF，保留全部正文和思考；EOF、部分正文后的错误均明确报错。
4. 额度缺失返回未知，真实零值返回零；优先保留上游套餐名。JSON、Bearer、Authorization 和 Cookie 粘贴按说明归一化。
5. 内核关闭闩在命令入队时更新；旧自动重启和旧停止命令不覆盖更新的手动操作意图。
