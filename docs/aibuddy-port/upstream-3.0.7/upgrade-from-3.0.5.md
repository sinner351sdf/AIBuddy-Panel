## 上游 3.0.7 与本地新增

3.0.7 的 WorkBuddy 5.8.4 头族、OrcaTerm 不可用模型报错与模型清单、AutoClaw 新手奖励、内核手动关闭保护、添加入口去重，已在之前的 3.0.7 条目中写明，本次累计说明继续保留；OrcaTerm 整套新接入和网页会话保活的独立默认关闭开关也包含在内。

前一版说明只说“保留 AI 助手”，不足以说明 3.0.5 用户会获得的新能力。本次单独补充本地启用和增强部分：

- AI SDK 与现有 Rust 网关、流式回答、思考和工具步骤、模型搜索与能力标签。
- 图片／文本附件、拖放与粘贴、复制和保留附件的重新生成；明确不支持任意 PDF／Office 解析。
- SQLite 历史对话、搜索／重命名／切换／删除、冲突保存保护；恢复对话不自动重跑工具。
- 两个只读工具默认启用，修改和模型测试手动启用并逐次确认；权限撤销、停止、字段保存和设置同步。
- 助手实际用量与来源筛选；上下文 Token 本地估算，图片未计入。

此外保留本轮已经写入的补偿积分、成长任务确认修复、积分抽屉、账号池按钮布局、整条分组点击和整卡选择。
