## 数据、历史与权限适配

本地 v12 的任务表、v13 的 account_history 保留；新增 v14/v15。在导入或启动时按实际表和 `requests.client` 列检查两个分支的历史结构，补建缺失对象。保留旧对话正文和现有请求、统计、签到及任务清理设置，没有采用上游一次性清空正文或统一替换保留期的做法。新客户端分类字段对旧请求留空。

升级前使用 SQLite Backup API 保存一致性快照，文件以私有权限建立；快照失败不继续升级。更高版本数据库拒绝降级。

账号写入、刷新、导入与覆盖保存时先保存不含凭据的历史身份，再加密凭据，并在同一账号写事务中提交。账号表触发器继续兜底提供商，统计不依赖明文 JSON。历史补齐遵循可靠证据，不从昵称猜测提供商；自定义提供商标签也保留历史快照。

账号与网关 Key 使用 AES-256-GCM；密钥留在 `account.key` 或 `AGENT2API_ACCOUNT_KEY`。密钥文件以 `create_new` 和创建时 0600 权限写入，防止多实例覆盖；密钥错误不退回明文，不删除不可解密账号，密文不能通过网关鉴权。JSON 恢复支持加密备份往返和旧明文导入，明文导入立即加密；保留旧 `priorityScope` 裸字符串格式。SQL 恢复在暂存库完成旧凭据加密后才激活，密钥指纹不符保留记录并明确提示恢复原密钥。

受限 Key 的额度、有效期和模型/提供商范围保留，所有管理接口隔离继续生效。安装、回滚和服务重启要求面板管理员或本地桌面管理能力。面板会话重启后可恢复；退出、改密与恢复备份仍撤销旧会话。

## 业务与界面适配

整合空思考帧、用量解析、工具签名、413/确定性 404、家内轮询和会话粘性等修复。自动续写默认关闭、默认上限 3 次；保留原 Accio 流式、阶段耗时和 Key 记账。初次请求的进程起始时间改为在请求统计初始化时确定，避免首条请求被错误识别为旧进程遗留请求而丢失实时耗时。

纳入正式版与 beta 的提供商兼容和额度明细；空值保持未知，真实零值保留，套餐名称优先上游原文。保留本地 Accio 剩余百分比口径，实际钱包余额按钱包单位显示。

代理加入可配置端口范围/测试地址、按需监听、补建和回收、下载目录/线路/取消；沿用现有代理引用。相同名称的两个订阅节点通过独立别名和内联配置隔离，不退回另一个订阅的同名节点。界面使用现有 Card、Table、Dialog、Field、Select、ToggleGroup、数字分页及行数控件，小屏动作区自动换行。

模型测试增加协议、临时代理和强制直连；自定义模型加入聚合视图。报表增加自定义日期和按模型明细提示，保留现有 shadcn Charts、配色、Token 数量趋势、黑色浅色环图百分比及热力图。侧栏、面包屑、页签、文档、提示与通知共享状态继续沿用本地实现。移动内容区适配上游能力，外壳保留本地抽屉；PWA 清单和图片使用本地品牌资产，没有离线缓存敏感接口。

## 容器更新和构建

Dockerfile 与 compose 的 `AGENT2API_SELF_UPDATE` 默认均为 0。Linux amd64/arm64 包、对应 `.sha256` 和 `update-manifest.json` 由本仓库构建。交叉构建显式指定两个 Rust target，避免 Apple 芯片主机为 amd64 意外复制 ARM 二进制。Windows/macOS 构建链继续保留。

更新须校验来源域名、校验文件大小与 SHA256、包内版本及 schema 兼容信息；拒绝路径穿越，程序与界面成套替换。替换前保存数据库快照，并写入旧程序的兼容清单。下载、安装及回滚互斥，已应用待重启时拒绝再次覆盖备份。兼容回滚成套恢复程序和界面；旧 schema 不兼容、元数据或界面备份缺失时阻止回滚，不自动覆盖升级后的数据库。

前端产物一致性 CI 从组件与翻译源码重建并比较；39 个上游生成产物没有手工合并。本次还补充了备份、加密历史身份、更新安全与日期筛选回归。

## 验收与复现

详细结果见 [validation.md](validation.md)。所有接口、内核和容器测试使用独立目录、临时端口及合成账号/节点。编译及本地夹具不代表真实提供商线上账户已验证；不运行有真实调用成本的账号任务。

主要命令：

```sh
cargo test --manifest-path desktop-tauri/src-tauri/Cargo.toml --target-dir target -p agent2api-server --lib
cargo check --manifest-path desktop-tauri/src-tauri/Cargo.toml --target-dir target -p workbuddy-proxy-desktop
npm --prefix desktop-tauri/ui-islands run build
node scripts/check-shadcn-ui.mjs --self-test
node desktop-tauri/i18n/scan.mjs --check
python3 scripts/test-upstream-3.0.5.py
```

Python 的加密验证脚本需要 `cryptography`；这是测试依赖，不是服务端运行依赖。`scripts/test-container-update.py` 需预先构建隔离镜像和双架构 bundle，再用 `--bundles` 指向导出目录；脚本只挂载自行创建的临时数据卷，结束后移除测试容器。
