## 本次额外修复

1. **启动和回归脚本误用旧程序。** Cargo 配置把产物放在项目根 `target/`，已有脚本却指向 `desktop-tauri/src-tauri/target/`，可能继续启动历史二进制。本次统一为根 `target/debug/agent2api-server`，启动脚本显式指定同一个 `--target-dir`。HTTP 回归全部在修正路径后重新执行；先前旧程序的结果不计入下表。
2. **headless 内核停机清理。** 上游只在桌面退出路径清理订阅内核，本次在共享关闭信号与 headless 退出收尾增加同一钩子，与既有 Clash 节点清理并存。这是源代码层的停机适配，未实际安装 mihomo 验证真实子进程生命周期。
3. **SQL 恢复暂存库。** 原实现删除暂存文件后以仅 READ_WRITE 的标志打开，无法创建不存在的文件；按 PID/毫秒生成名字还会让并发恢复争用路径。现在采用随机文件名与排他创建，不删除其他恢复的暂存文件，保留 Drop 清理；SQL authorizer 设置失败会拒绝继续。新增测试验证两个独立暂存库不会覆盖彼此，且分别清理。
