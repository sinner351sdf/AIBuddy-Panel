# 助手工具开关修复（2026-10-16）

原问题：聊天输入框下方的工具浮层只显示已启用 / 未启用，无法在当前位置授权。工具功能已有实现；默认两个只读工具，其余修改和测试工具需手动启用。

## 改动

- 使用现有 Base UI Switch 与 Label，为全部九项工具提供可点击、可通过键盘操作的开关。
- 沿用 `saveAssistantConfig`，每次 PATCH 仅提交当前工具的布尔值，成功后由共享配置快照更新浮层、数量、顶部权限说明和配置页。
- 保存中阻止重复提交；仅在服务端成功后更新状态，失败显示错误并允许重试。
- 提示开关自动保存；保留只读默认与修改、测试逐次确认，以及原有提示词、模型和数据。
- 五种语言补齐新增说明，重新生成词典和前端产物。

## 验证

- `node scripts/test-assistant.mjs`：通过，新增浮层开关保存失败、延迟保存、重复点击、字段独立更新和权限撤销回归；从浮层开启修改工具后仍需确认，不会自动修改。
- `node scripts/test-assistant.mjs --no-model`：通过。
- TypeScript / Vite 构建、shadcn 检查、i18n 完整性检查：通过。
- 使用临时数据库、模拟提供商和独立 localhost 浏览器 Cookie 验证双向同步：浮层启用后设置页勾选，设置页关闭后浮层恢复关闭，数量 3/9 → 2/9。

本次为前端改动，静态产物构建后由现有 3065 服务直接提供，无需重启 Rust 后端。没有提交、推送或发布。
