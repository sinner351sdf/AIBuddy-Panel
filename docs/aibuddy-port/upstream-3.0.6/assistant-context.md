# 助手上下文用量（2026-10-16）

在模型选择旁新增可点击的上下文用量入口，显示估算 Token 或占模型窗口的百分比。浮层包括系统提示词、工具定义、对话内容（含工具结果和已发送文本附件）、待发送内容（输入文字及待发送文本附件）。可关闭、键盘访问，支持深浅主题及手机布局。

## 数据口径

- 按实际发送的消息转换、工具 JSON 和提示词注入规则本地估算，不执行额外模型请求。Latin 字符约四个 / Token，其他字符约一个 / Token；不是模型精确分词或累计计费用量。
- 提示词关闭或工具全关闭时不计入 system，与 Rust 的注入规则一致。隐藏思考不会发回模型，因此不计入。
- 图片不按 base64 长度估算，显示未计入提示；文本文件复用已有 UTF-8 校验/转换，取消或移除时停止旧读取，发送与切换对话后清理待发送附件。
- 上限来自所选对外模型/别名的 maxInputTokens；多条已启用线路全部声明上限时取最小值。任一线路未知则显示上限未知，不伪造百分比。达到上限给出提示，不改变原发送行为。
